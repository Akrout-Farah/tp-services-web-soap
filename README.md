
# TP Services Web SOAP – JAX-WS

Deux projets Maven qui montrent le fonctionnement d'un service web SOAP en Java :
un serveur qui expose une calculatrice, et un client qui la consomme.

(TP2.1-CalculatriceWS) | Service web SOAP (serveur) |
(TP2.2-client-soap) | Client SOAP (stub généré avec wsimport) |

## Ordre d'exécution

1. Lancer le serveur du TP 1 (`ServeurJWS`) et le laisser tourner.
2. Générer le stub du TP 2 (`jaxws:wsimport`).
3. Lancer le client (`ClientSOAP`).
